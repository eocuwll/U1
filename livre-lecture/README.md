# Je lis, j'écris ! — 21 jours (CE1)

Livret imprimable (A4, 76 pages) pour relancer la lecture et l'écriture après une longue pause.

- `Je-lis-j-ecris-21-jours-CE1.pdf` : le livre prêt à imprimer.
- `contenu.py` : textes, mots, exercices, dictées (modifiable).
- `build.py` : génération du PDF (`pip install reportlab uharfbuzz fonttools` puis `python3 build.py`).
- `fonts/` : Andika et Playwrite France Moderne (SIL Open Font License, Google Fonts).
